Quick Start Guide

Get up and running with AISEO in 5 minutes. This guide will walk you through setting up your first project and tracking your brand's AI visibility.

Step 1: Create Your Project

Every campaign in AISEO starts with a project. A project represents your brand, website, or product that you want to track across AI platforms.

  1. Navigate to Projects - Click on "Projects" in the main navigation
  2. Create New Project - Click the "New Project" button
  3. Enter Project Details
    • Project Name (e.g., "My Brand")
    • Website URL (e.g., "https://yourbrand.com")
    • Industry/Category
  4. Save - Click "Create Project" to save
💡
Pro Tip:

You can create multiple projects to track different brands, products, or websites separately.

Step 2: Add Competitors

Track how your brand compares to competitors in AI-generated responses.

  1. Go to Competitors - Navigate to the Competitors page
  2. Add Competitor URLs - Enter competitor website URLs (comma or newline separated)
  3. Save - AISEO will automatically fetch competitor information

Step 3: Set Up Prompt Tracking

Define the prompts and questions you want to monitor across AI platforms.

  1. Navigate to Prompt Research
  2. Add Prompts - Enter questions your target audience asks 
    Example prompts:
- "What are the best SEO tools?"
- "How to improve website ranking?"
- "Top content marketing platforms"
  3. Select Platforms - Choose which AI platforms to track (ChatGPT, Claude, Perplexity, etc.)
  4. Start Tracking - AISEO will begin monitoring these prompts

Step 4: Run Your First Site Audit

Get a comprehensive analysis of your website's technical SEO and AEO optimization.

  1. Go to Site Audits
  2. Click "Start Scan"
  3. Wait for Results - The audit typically takes 2-5 minutes
  4. Review Issues - See categorized issues (Critical, High, Medium, Low)
  5. Take Action - Follow recommendations to improve your scores

Step 5: Monitor Your Visibility Dashboard

Track your brand's visibility across AI platforms in real-time.

Visibility Score

Overall score indicating how often your brand appears in AI responses

Share of Voice

Your brand's mention percentage compared to competitors

Citations

Track which sources AI platforms cite when mentioning your brand

Platform Breakdown

See performance across ChatGPT, Claude, Perplexity, and more

Step 6: Create Optimized Content

Use AISEO's AI-powered content creation to generate content that gets cited.

  1. Navigate to Content Creation
  2. Select a Topic - Choose from your tracked topics or enter a new one
  3. Choose Target Prompts - Select which prompts this content should target
  4. Select Platforms - Choose which AI platforms to optimize for
  5. Generate - Let AI create optimized content
  6. Review & Publish - Edit as needed and publish to your website

Best Practices

1. Track Relevant Prompts

Focus on prompts that your target audience actually uses. Use tools like:

  • Google Search Console to find questions people ask
  • Reddit and Quora for common questions in your industry
  • Customer support tickets for frequently asked questions

2. Monitor Regularly

Check your visibility dashboard at least weekly to:

  • Track trends and changes
  • Identify new opportunities
  • Spot potential issues early

3. Fix Critical Issues First

When reviewing site audit results:

  • Start with Critical severity issues
  • Focus on issues affecting multiple pages
  • Prioritize AEO-related issues for AI visibility

4. Create High-Quality Content

AI platforms favor authoritative, well-structured content:

  • Use clear headings and structure
  • Include data and statistics
  • Cite credible sources
  • Answer questions directly and comprehensively

Common Workflows

Weekly Monitoring Workflow

  1. Check Visibility Dashboard for score changes
  2. Review new mentions and citations
  3. Analyze competitor performance
  4. Identify content opportunities
  5. Create or optimize content based on findings

Monthly Optimization Workflow

  1. Run a fresh site audit
  2. Fix high-priority issues
  3. Review prompt performance
  4. Add new prompts based on trends
  5. Update competitor list if needed
  6. Generate monthly performance report

Troubleshooting

Low Visibility Score?

  • Ensure your website has sufficient high-quality content
  • Check that your site is properly indexed
  • Review and fix site audit issues
  • Create content targeting your tracked prompts

No Citations?

  • Improve content authority with data and sources
  • Add structured data markup
  • Build backlinks from authoritative sites
  • Ensure content directly answers common questions

Competitors Outranking You?

  • Analyze their content strategy
  • Identify gaps in your content
  • Create more comprehensive content
  • Improve technical SEO scores
