# Caption fonts - licences

These font files are used by ffmpeg/libass to render burned-in captions. They are not installed system-wide: the renderer loads them
directly from this directory through the `fontsdir` option of the `subtitles` filter. The 17 fonts the browser preview needs are also
served from `AppBackendBasic.WebUI/public/caption-fonts` (same files, with their own `OFL.txt`).

All files are free for commercial use, including bundling them in this application and in videos users export. Conditions:

- **Do not sell the font files on their own.**
- **Keep the licence with the files** whenever they are handed to someone else (the browser download counts, so `OFL.txt` sits next to
  the preview fonts).
- **Do not change a font's design and keep its name.** Several fonts have a Reserved Font Name (Lora, Lobster, Playfair Display,
  Righteous, Titan One, IM FELL English, IBM Plex). A modified version must be renamed. Format conversion (woff2 -> ttf) does not change the design.

Licence texts in this folder: `OFL.txt` (SIL Open Font License 1.1, all fonts except one) and `Apache-2.0.txt` (Permanent Marker).

Sources: Google Fonts static instances (the API's fonts.gstatic.com files or the `@fontsource/*` npm packages, which redistribute them),
converted from `.woff2` to `.ttf` with `fonttools` where needed, because libass needs TrueType/OpenType instead of a web format.

Deliberately NOT bundled:
- an upright Playfair Display Bold, because libass would then pick it even for the italic Playfair requests Street Glow makes;
- Bungee, because libass sizes it from very tall vertical metrics, so it renders at half the size the browser shows;
- Komika Axis (used by the original tscaps "loki" template), because it is not under an open licence. Bangers replaces it.
